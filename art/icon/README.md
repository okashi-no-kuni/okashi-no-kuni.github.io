**角丸が 絵に 焼きこまれていて、その外がわが 黒**でした。
iOS の 角丸マスクを かけると 二重に なり、四すみに 黒が のこります
（実測：すみの はんいの **8.2%**）。同じ 絵の 角丸なし版を もらって
差しかえました。**この失敗は もう一度 起こしやすい**ので、
新しい 絵を もらう ときは かならず「角を まるめない・ふちまで 塗る」と
つたえてください。

## 差しかえかた

1. 新しい 原画を この フォルダに 置く（**古いものは 消さない**）
2. 上の 表を 書きかえる（サイズ・バイト数・SHA-256）
3. `node tools/make-icons.mjs` … アイコン7つを ぜんぶ 出しなおす
   （起動画面は 4〜5分 かかります。急ぐときは `--no-splash`）
4. `npx capacitor-assets generate --ios` … iOS の アイコンを 切り出す
5. `node tools/build-sw.mjs` … web版の キャッシュの 版を 上げる

## この フォルダは アプリにも キャッシュにも 入りません

`tools/_files.mjs` の ならびに 入れていないので、
`www/`（アプリ）にも `sw.js`（オフライン）にも 入りません。
**原画は 配る もの では なく、作りなおす ため の もの**です。
