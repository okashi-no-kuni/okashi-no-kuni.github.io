## そのままでは App Store に 出せません

**角丸が 絵に 焼きこまれていて、その外がわが 黒**です。
iOS は アイコンに **自分で** 角丸の マスクを かけるので、二重に なって
**四すみに 黒い かけらが のこります**（実測：すみの はんいの **8.2%** が 黒）。

このリポジトリの きまりにも 書いてあります ——
「**角を自分でまるめない**。iOSもAndroidも自分で切りぬくので、二重になります。
ふちまで色を塗った四角を出すこと」（`CLAUDE.md`）。

直しかたは 3つ。**どれも 原画は さわりません。**

| | やること | 見た目 |
|---|---|---|
| **A（おすすめ）** | 角丸なし・ふちまで 絵が つづく 版を もう一度 もらう | いちばん きれい |
| B | 角の外の 黒だけを、ふちの 金色で ぬりつぶした **派生ファイル**を 作る | ほぼ きれい。原画は のこる |
| C | すこし 拡大して 黒を 外へ 出す | **トリミングに なる**ので しない |

## 差しかえかた

1. 新しい 原画を この フォルダに 置く（**古いものは 消さない**）
2. 上の 表を 書きかえる（サイズ・バイト数・SHA-256）
3. `node tools/make-icons.mjs` … いまは **コードで えがいた 案**を 出します。
   支給された 絵に 切りかえる ときは、この どうぐの 出しくちを
   `art/icon/` の ファイルに 差しかえます
4. `npx capacitor-assets generate --ios` が `assets/icon.png` から
   iOS の アイコンを ぜんぶ 切り出します

## この フォルダは アプリにも キャッシュにも 入りません

`tools/_files.mjs` の ならびに 入れていないので、
`www/`（アプリ）にも `sw.js`（オフライン）にも 入りません。
**原画は 配るもの では なく、作りなおす ため の もの**です。
