1. **Apple Developer Program に 入る**（年 ¥14,800／個人）
   審査に 出せるように なるまで 数日 かかることが あります。
2. ~~サポートページの 連絡先を 埋める~~ **すみ**
   `okashinokuni.game@gmail.com`（このアプリ専用に 作った もの）。
   **ふだんの 個人アドレスを 書かないこと** ——公開ページなので
   迷惑メール業者に かならず 拾われます。
3. **App Store Connect で アプリを 作る**
   バンドルID は 上の とおり。プラットフォームは iOS。
4. **API キーを 作って GitHub の Secrets に 入れる**
   やりかたは `.github/workflows/ios.yml` の 上の コメントに あります。
5. **ワークフローを 手で 走らせる**（Actions → 「iOS を 組んで App Store へ 送る」）
   1回目は `upload` を **false** に して、組めるところまで 確かめる。
6. 通ったら `upload` を **true** で もう一度。
7. App Store Connect で ビルドを えらび、下の 文言と スクショを 入れて 提出。

## 6. 審査で きかれそうな こと（先に こたえを 用意しておく）

「App Review に関する情報 → メモ」に そのまま 貼れる 文です。

```
・本アプリはサーバーを持たないオフラインゲームです。ネットワーク通信は
  一切行いません（fetch / XMLHttpRequest / WebSocket をコードに含みません）。
  機内モードでも全機能をご確認いただけます。

・アカウント登録はありません。ログイン情報は不要です。

・本バージョンにアプリ内課金はありません。ゲーム内通貨「ジュエル」は
  ログインボーナス等で配布するもので、実際の金銭では購入できません。
  ショップ画面にも金額表示はありません。

・ランダム性のある要素（たまご）については、ゲーム内の「たまごを開く」画面に
  排出確率を常時表示しています（ガイドライン3.1.1／日本の景品表示法）。

・「ともだちに おしえる」画面から LINE / X / Instagram / TikTok を
  開くことがありますが、いずれもユーザーが明示的にボタンを押した場合のみで、
  送信されるのは共有用リンクとテキストのみです。

・アバターの名前（全角8文字まで）は端末内に保存され、ユーザーが自分で
  「合言葉」を作って手動で共有した場合にのみ、受け取った相手の画面に
  表示されます。サーバーも公開フィードも検索機能もなく、
  不特定多数に配信される仕組みはありません。

・進行状況はすべて端末内（localStorage）に保存され、外部へ送信されません。
```

### ユーザー生成コンテンツ（1.2）について

アバターの名前は **8文字まで**の 自由入力です。ともだちが 合言葉を
手で 貼りつけた ときだけ、その名前が 相手の 画面に 出ます。

- サーバーが 無い／公開の 場が 無い／検索も 無い ので、
  ガイドライン 1.2 が いう「UGCを 含む App」には あたらないと 考えています
- もし 審査で きかれたら、上の メモの 段落を そのまま こたえてください
- それでも 求められた ときの 手は 2つ
  ① 名前を **決まった 語の 組み合わせ**（例：「ぴんく」＋「うさぎ」）に する
  ② 受け取り側で 名前を 出さず、アバターの 絵だけを 出す

どちらも 1.0 では 入れていません。**先まわりして 機能を 削らない**
——きかれてから 直すほうが、ゲームとして 良い形を のこせます。

## 8. 1.1 で 課金を 入れるとき

用意は ぜんぶ できています。やることは この 4つだけです。

1. `index.html` の **`IAP_ON` を `true`** に する
   → 💎パック・復元ボタン・年齢と上限が いっぺんに 出てきます
2. App Store Connect で 商品を 登録する（下の 表）
3. `payGems()` と 💎パックの ボタンを StoreKit 2 に つなぐ
   （買いものの 口は **`payGems()` 1か所**に まとめてあります）
4. `receiptOwned()` を レシート照会の こたえに さしかえる
   （`?dbg=1` の `__dbg.setReceipt()` で ためせます）

| 商品ID | 種類 | 中み | ねだんの 目やす |
|---|---|---|---|
| `gems_60`  | 消耗型 | 💎60 | ¥320 |
| `gems_200` | 消耗型 | 💎200 | ¥980 |
| `gems_550` | 消耗型 | 💎550 | ¥2,500 |
| `pack_start` | 非消耗型 | はじめてパック（⭐3,000＋★4の なかま1人） | ¥480 |
| `pass_30` | 消耗型 | 30日パスポート | ¥1,200 |

- **⭐は 単品で 売らないこと**（後半は 1ウェーブで 何万も 入るので、
  買った ⭐が すぐ 値うちを なくして「損した」に なる）
- **強さそのものを 売らないこと**（攻撃力・レベル上限）
- **非消耗型を 売るなら 復元ボタンが 必須**（Apple の きまり）。
  `restorePurchases()` の 中を `restoreCompletedTransactions()` に
  さしかえるだけです
- 未成年の ひと月の 上限（`canPayYen` → `recordYen`）は もう 通り道が
  できています。**先に 記録しないこと** ——買いものを やめたり
  失敗したときに、はらっていない お金が 引かれます
