# えいごの おかしの国 — UIイメージ（モック）

英語学習ゲーム（日本語↔英語の マッチング）の **見た目を 決めるための 板**です。
ゲーム本体では ありません。ここで 形が 決まったら、あらためて 実装します。

```
node mock/english/shot.mjs      # shots/ に 6まい ＋ ならべた 1まい
```

| | |
|---|---|
| `ui.html` | 6画面の モック（iPhone 実寸 393×852 を 6つ ならべた 1ページ）|
| `shot.mjs` | 画面ごとに 1まいずつ 撮る（Playwright）|
| `shots/` | 出てきた 絵 |

## この モックで 決めている こと

- **アートディレクションは シリーズ共通**（`CLAUDE.md`）。パステル・角丸・
  紫がかった かげ・4方向の キラキラ・丸ゴシック。**新しい 絵柄を 作らない**
- **キャラは 既存の `art/sprites/` を そのまま つかう**。160体 あるので、
  どうぶつ・たべものの 単語は 絵を 出しなおさずに 作れます
- **マッチングは 2列**。左＝日本語（絵つき）／右＝英語。そろうと ミントの
  リボンで つながって ✓。リボンは **札の いちを 測って 引く**ので、
  札の 大きさを 変えても ずれません（数字を 2か所に 書かない）
- **発音は そろった しゅんかんに 出す**。絵・英語・発音記号・カタカナ・日本語を
  1枚に まとめ、🔊の わっかで「いま 鳴っている」ことを **止まった絵でも** 見せます
- **音は かならず オン・オフ できる**（シリーズの きまり）。盤面の 🔊 と
  せってい画面の 2か所から。**音を 切っても 遊べる**こと
- **むずかしさは ウェーブで 上げる**。単語の 長さ → 数 → 抽象度（きもち・うごき）
  → 文。「みちのり」画面で 先の 見とおしを 見せて、つぎへ つなげます

## まだ 決めていない こと（相談したい）

1. **発音の 出しかた** —— 端末の 読みあげ（Web Speech API・ファイル不要）か、
   mp3 を こちらで 用意するか。iPhone は Safari でも 英語の 声が 入っていますが、
   声の しゅるいは 端末まかせに なります
2. **タップ式 か ドラッグ式 か** —— いまの モックは「左を タップ → 右を タップ」。
   指で 線を ひっぱる 形も できます（小さい子には タップの ほうが かんたん）
3. **時間制限と ミス** —— いまは のこり時間の バーと「ミス 0」を 置いていますが、
   時間切れで 終わるのか、ミスで 💗が へるのかは 未定
4. **単語の しいれ** —— 絵の ある 単語（既存スプライト）と、絵の ない 単語
   （色・数・きもち・動詞）で 札の 作りを 変えるか
5. **別アプリ か 中に 入れるか** —— いまの タワーディフェンスとは 別の
   `english.html` に するのが 素直です（盤面の 作りが まったく ちがうため）
