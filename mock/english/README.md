# えいごの おかしの国 — UIイメージ（モック）

英語学習ゲーム（日本語↔英語の マッチング）の **見た目を 決めるための 板**です。
ゲーム本体では ありません。ここで 形が 決まったら、あらためて 実装します。

**対象は 小学生〜大学生。**同じ 仕組みのまま、コースで 見せかたを 変えます。

```
node mock/english/shot.mjs      # shots/ に 9まい ＋ ならべた 1まい
```

| | |
|---|---|
| `ui.html` | 9画面の モック（iPhone 実寸 393×852 を ならべた 1ページ）|
| `shot.mjs` | 画面ごとに 1まいずつ 撮る（Playwright）|
| `shots/` | 出てきた 絵 |

## 画面

| | |
|---|---|
| ① 表紙 | 小学・中学・高校・大学＆TOEIC の 4つを 先に 見せる |
| ② コースを 選ぶ | 学年は 目安。**ロックしない**（下の 復習も 上の 挑戦も できる）|
| ③ 盤面・初級 | 4組・絵つき・かな。小学生向け |
| ④ 盤面・上級 | 6組・絵なし・発音記号・品詞。高校〜大学・TOEIC |
| ⑤ 正解→発音（初級）| 絵・カタカナ・日本語 |
| ⑥ 正解→発音（上級）| 発音記号・品詞・検定タグ・例文 |
| ⑦ ウェーブクリア | 結果と 次の 予告 |
| ⑧ ウェーブの 道のり | いまの コースの 前後と 難易度 |
| ⑨ 音と 表示の 設定 | 発音 ON/OFF・速さ・出題の 向き・カタカナ・例文 |

## この モックで 決めている こと

- **アートディレクションは シリーズ共通**（`CLAUDE.md`）。パステル・角丸・
  紫がかった かげ・4方向の キラキラ・丸ゴシック。**新しい 絵柄を 作らない**
- **年齢で ゲームを 分けない。**盤面は 1つで、コースによって
  **絵・カタカナ・発音記号・例文・組の数**を 出し入れするだけ。
  小学生に 発音記号は 出さず、大学生に 動物の 絵は 出しません
- **UIの 日本語は 漢字・カタカナ**（`CLAUDE.md` の きまり）。
  かなで のこすのは **世界の 名前と キャラのセリフだけ**
  （「どうぶつの もり」「えいごの おかしの国」）。
  大学生が 見る 画面で「せいかい」「はつおん」は 幼く 見えます
- **学年で ロックしない。**中学生が 高校の 語に 挑戦する ことも、
  大学生が 中学の 語を 復習する ことも ある。かわりに
  **30秒の レベル判定**で 入口を 決めます
- **キャラは 既存の `art/sprites/` を そのまま つかう**。160体 あるので、
  初級の 絵は 出しなおさずに 作れます。上級は 絵が 要りません
- **マッチングの リボンは 札の いちを 測って 引く**ので、
  4組でも 6組でも 同じ コードで 動きます（数字を 2か所に 書かない）
- **音は かならず オン・オフ できる**（シリーズの きまり）。盤面の 🔊 と
  設定の 2か所から。**音を 切っても 遊べる**こと

## まだ 決めていない こと（相談したい）

1. **語彙リストの 出どころ** —— 英検・TOEIC の「単語」そのものに 権利は
   ありませんが、**市販の 単語集の ならびを そのまま 写すのは だめ**です。
   自前で 作るか、再配布できる リスト（NGSL など）から 組むか
2. **発音の 出しかた** —— 端末の 読み上げ（ファイル不要・声は 端末まかせ）か、
   mp3 を 用意するか。7,200語 ぶんの mp3 は アプリの 容量に ひびきます
3. **間隔をあけた 復習** —— いまは「間違えた語は 日を おいて もう一度」と
   だけ 書いています。何日後に 何回 出すかは 未定
4. **時間制限と ミス** —— 残り時間バーと「ミス」を 置いていますが、
   時間切れで 終わるのか、ミスで 💗が 減るのかは 未定
5. **別アプリ か 中に 入れるか** —— 盤面の 作りが まったく ちがうので、
   `english.html` を 新しく 作るのが 素直です
