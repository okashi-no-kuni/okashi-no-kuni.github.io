# WORDLINK（英単語リンク）— UIイメージ（モック）

日本語と 英語を つないで 消す ゲームの **見た目を 決めるための 板**です。
ゲーム本体では ありません。

**「まほうの おかしの国」とは 別のゲーム**として 作っています。
見た目が 似ていると、同じ 世界の 続編に 見えて どちらの 印象も ぼやけるためです。

```
node mock/wordlink/shot.mjs      # shots/dark/ と shots/light/ に 7まいずつ
```

## おかしの国と 何を 変えたか

| | おかしの国 | WORDLINK |
|---|---|---|
| 主役 | キャラクター（128体）| **単語そのもの**（キャラは 出さない）|
| 配色 | パステル（ピンク・ラベンダー・ミント）| 紺＋シアン／白＋青。ダークとライトの 2つ |
| 文字 | 丸ゴシック・かな多め | システムのゴシック・漢字／英字は 太字で 詰める |
| 角丸 | 14〜20px | 10〜16px |
| 影 | 紫がかった 半透明 | 黒の 低い 影（ライトでは ほぼ 無し）|
| アイコン | 絵文字 | **線の SVG**（端末で 見た目が 変わらない）|
| 音 | 効果音と BGM が 主役 | 発音の 読み上げが 主役 |
| 絵素材 | `art/sprites/` 160体 | **画像を 1枚も 使わない**（文字と 線だけ）|

**おかしの国の 素材・配色・部品は 1つも 持ちこんでいません。**

## 画面

| | |
|---|---|
| ① タイトル | つながりの 図が 表紙の 絵。何をする ゲームかが 1枚で わかる |
| ② レベルを選ぶ | L1小学／L2中学／L3高校／L4大学・TOEIC／MIX総復習。**学年で ロックしない** |
| ③ 盤面 | 左＝英語＋発音記号＋品詞、右＝意味。5組。つながると 緑の 線 |
| ④ 正解 → 発音 | 下から 出る シート。波形・例文・検定タグ |
| ⑤ ウェーブ結果 | 正解率・時間・連続・XP、次の ウェーブの 予告、この回の 5語 |
| ⑥ 記録 | 連続日数・今週の 学習時間・覚えた語・復習の たまり・よく間違える語 |
| ⑦ 設定 | 発音・速度・出題の向き・発音記号／カタカナ／例文・画面・1日の目標 |

## 決めている こと

- **キャラクターを 出さない。**主役は 単語。にぎやかさは 線と 数字で 出します
- **年齢で ゲームを 分けない。**盤面は 1つで、レベルによって
  **発音記号・カタカナ・例文・組の数**を 出し入れするだけ
- **学年で ロックしない。**小学生が 上を のぞくのも、大学生が 中学を
  復習するのも ふつうの ことなので。迷う人には 30秒の レベル判定
- **色だけに たよらない。**正解した 組は「緑の 線」「左の 帯」「チェック」の
  3つで 示します。色が 見分けにくい 人にも 伝わるように
- **円グラフを 使わない。**1つの 割合は 大きな 数字と 細い バーの ほうが
  速く 読めます（正解率・進みぐあい とも）
- **今週のグラフは 1系列**なので 凡例を 置かず、**今日だけ 濃く**します
- **ダークと ライトの 両方**を 同じ HTMLから 出します
  （`html[data-theme]` を 切りかえるだけ）。夜に 勉強する人が 多いので
  ダークを 既定に していますが、まだ 決めきっていません

## まだ 決めていない こと（相談したい）

1. **名前**（WORDLINK は 仮）。日本語名・ロゴの 形も これから
2. **ダークを 既定に するか**。教室や 昼に 使うなら ライトの ほうが 自然です
3. **語彙リストの 出どころ** —— 単語そのものに 権利は ありませんが、
   市販の 単語集の ならびを そのまま 写すのは だめ。自前で 作るか、
   再配布できる リスト（NGSL など）から 組むか
4. **発音の 出しかた** —— 端末の 読み上げ（追加ファイル不要・声は 端末まかせ）か、
   mp3 を 用意するか
5. **制限時間と ミスの あつかい** —— いまは 90秒の タイマーと 連続ボーナス。
   時間切れで 終わるのか、間違いで 減点なのか
6. **実装の 土台** —— 画像を 使わないので Canvas も Phaser も 要りません。
   1枚の HTML＋CSS＋JS（DOM）で 足ります
