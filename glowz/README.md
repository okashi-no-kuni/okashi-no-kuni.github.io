# GLOWZ / Glowz Planet

夜職店舗のための **AI経営プラットフォーム**。
ブランドガイド（ChatGPT作成のデザイン見本）から起こした、動くプロトタイプです。

| 画面 | 場所 | 色 |
|---|---|---|
| ブランド一覧 | `index.html` | Champagne |
| BUSINESS OS（店舗経営） | `business/index.html` | Pearl White × Silver |
| THERAPIST OS（キャスト） | `therapist/index.html` | Pearl Pink × Silver |
| CUSTOMER WEB（お客様） | `customer/index.html` | Pearl Champagne × Silver |

いまはサーバーを使わない **静的HTML＋ダミーデータ** です。
GitHub Pages にそのまま乗り、営業資料としても見せられます。

---

## 色は `data-brand` ひとつで切りかわる

`<html data-brand="therapist">` と書くだけで、そのページの色がすべて変わります。
**ページ側に色を直接書かないこと。** 書くと、ブランドを増やしたとき
（GLOWZ Manager / Cast / CRM …）に直す場所が散らばります。

| | `--bg-1` | `--bg-2` | `--bg-3` | `--accent` |
|---|---|---|---|---|
| `business` | `#F7F8FA` | `#E6E8EC` | `#C0C3C8` | `#3E8FD6` |
| `therapist` | `#FFF0F6` | `#FFD6E6` | `#D3D5DB` | `#F2529C` |
| `customer` | `#FFF7ED` | `#F1E6D3` | `#C8C8CF` | `#C9A24B` |

シルバー（`--sv-0`〜`--sv-5`）だけは3色すべてに共通で入るので、
`data-brand` で切りかえません。ブランドガイドの「共通要素：Pearl・Silver・
Aurora・Glass」がそのままトークンになっています。

---

## パールとオーロラはCSSで描く

デザイン見本のパール球とオーロラ背景は **AI生成の画像** でしたが、
ここでは CSS のグラデーションで作りなおしています。

- 拡大しても割れない（ロゴにもヒーローにも同じ `.pearl` を使える）
- ブランドごとに色が変わる（`--pearl-hi` 〜 `--pearl-sh`）
- 画像を1枚も読みこまないので、開いた瞬間から出ている

球に見せるには **ハイライト（左上）と反射光（下）の2つ**が要ります。
反射光を消すと、とたんに「ただの円」になります。

画像素材に差しかえたくなったら `.pearl` の `background` を
`url()` に替えるだけで、置き場所は変えずに済みます。

---

## 文字の大きさは `--fs` ひとつ

`glowz.css` の `font-size` はすべて `calc(◯px * var(--fs))` の形です。
`:root` の `--fs`（いま **1**）を変えると全体がまとめて変わります。

かけていないのは **絵文字アイコン**だけです。入れものの幅が固定なので、
大きくすると枠から出ます。

---

## グラフはCanvasで自前に描く

要るのは「折れ線」「ドーナツ」「スパークライン」の3つだけなので、
Chart.js は入れていません（初回表示が重くなるため）。

**隠れている画面のCanvasは幅0になります。** そのまま描くと
半径がマイナスになって `arc()` が例外を投げるので、`fitCanvas()` が
`null` を返して呼ぶ側が黙って戻ります。画面を切りかえたあとに
`draw()` を呼びなおせば、そのとき正しい幅で描けます。
（THERAPIST のタブ切りかえで実際に起きました）

`devicePixelRatio` にも合わせてあります。合わせないと Retina で
グラフだけぼやけます。

---

## 写真の枠は `<img>` を足すだけで差しかわる

人物写真はまだありません。いまは `.av`（イニシャルをのせたパール球）と
`.visual`（ヒーローの仮置き）で埋めてあります。

```html
<span class="av"><img src="…"></span>   <!-- これで写真になる -->
```

素材を入れるときは **商用利用可・再配布可**のものだけにしてください。
GitHub Pages に置く＝誰でもダウンロードできる状態になります。

---

## お客様向けサイトは年齢確認を通す

`customer/index.html` は成人向けサービスの入口なので、最初に年齢確認を出します。

`sessionStorage` にしているのは、**タブを閉じたらまた確認するため**です。
`localStorage` だと共用端末で次の人にも「確認済み」が引きつがれます。

---

## Appleに出すときの注意

**お客様向け（CUSTOMER）はネイティブアプリにできません。**
Appleは成人向けサービスの予約・紹介アプリを審査で通しません
（App Store Review Guideline 1.1.4 / 5.0）。
デザイン見本が CUSTOMER だけ「Web / PWA」になっているのは正しい判断です。

店舗管理側（BUSINESS / THERAPIST）は業務ツールなので余地がありますが、
どちらにせよ **まずPWAで作る**のが確実です。

## 検証

```
node tools/check-glowz.mjs
```

4画面 × 2サイズ（1440 / 390）を実際に開いて、次を見ます。

| | 見つかるもの |
|---|---|
| JSエラー | 描画中の例外 |
| 横はみ出し | 画面より広い要素 |
| Canvasが空 | 幅0のまま描けていないグラフ |
| タブ切りかえ | 画面が1まいずつ入れかわっているか |

Googleフォントは取りに行けない環境があるので、その失敗だけは対象外です。
