プライバシーポリシー

まほうのおかしの国をまもって（Sweet Kingdom Defense）
最終更新日：2026年9月1日

このゲームは、個人情報を いっさい あつめません。
名前・メールアドレス・電話番号・位置情報・連絡先・写真・音声を たずねることも、受け取ることも、送ることも ありません。 アカウント登録も ありません。

1. あつめる情報

ありません。このゲームには、あそんだ内容を 外へ送るしくみが 1つも 入っていません。分析ツール（アクセス解析）も 広告も 使っていないため、開発者が あなたの あそびかたを 知ることは できません。

2. 端末の中に のこるもの

あそびの つづきを 出すために、次のものを あなたの端末の中だけに 保存します（ブラウザの localStorage、アプリ版はアプリ内の保存領域）。 これらが 端末の外へ 出ることは ありません。

すすみぐあいウェーブ・おほしさま・げんき・おいた仲間
コレクション図鑑に入った子・かけら・ジュエル・アイテム
設定音のオンオフ・ふるえのオンオフ・着せかえ・アバター
記録自己ベスト・あそんだ回数・今週のおだいの記録

これらは いつでも消せます。アプリ版はアプリを削除すると、 ブラウザ版はブラウザの「サイトデータを消去」で すべて消えます。 消したものを 開発者が 復元することは できません（控えを持っていないためです）。

3. 通信について

このゲームには サーバーが ありません。アプリ版は、絵も音も プログラムも すべて アプリの中に 入っているので、 インターネットにつながっていなくても あそべます。 ブラウザ版は、ページを読みこむときに GitHub Pages（GitHub, Inc.）から ファイルを受け取ります。そのとき GitHub 側に 通常のアクセス記録が 残ることがあります（GitHub のプライバシーポリシーによります）。

4. 外部のアプリを開くとき

「ともだちに おしえる」や「記録をシェア」を あなたが押したときだけ、 LINE・X・Instagram・TikTok などを開くことがあります。 そのとき送られるのは あなたが書いた文とリンクだけで、 あそびの記録が いっしょに送られることは ありません。 開いたあとは、それぞれのアプリのプライバシーポリシーが適用されます。

5. 子どもの プライバシー

このゲームは 年齢を問わず あそべます。13歳未満の子どもを 含め、 だれからも 個人情報を あつめません。そのため、保護者の同意を いただく必要も ありません（COPPA・個人情報保護法）。

6. 端末の機能

位置情報・カメラ・マイク・連絡先・写真・カレンダー・ヘルスケアの データには いっさい アクセスしません。使うのは、音を鳴らすことと、 端末をふるわせること（Android のみ）だけです。

7. アプリ内課金

このバージョンには アプリ内課金が ありません。ゲームの中の ジュエル（💎）は あそんで手に入れるもので、お金では買えません。 将来 課金を入れるときは、Apple の App Store のしくみだけを使い、 このページも あわせて 更新します。クレジットカード番号などを 開発者が 受け取ることは、そのときも ありません。

8. このポリシーの変更

内容を変えたときは、このページの「最終更新日」を書きかえます。 大きな変更のときは、ゲームの中でも おしらせします。

9. お問い合わせ

ご質問・ご要望は サポートページから お願いします。
